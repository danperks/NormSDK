# Command reference

Generated by `cargo xtask docs` from the annotated catalog in [`crates/norm-sdk/src/catalog.rs`](../crates/norm-sdk/src/catalog.rs), merged with the replies recorded from the stock firmware running under emulation ([`tests/emulator`](../tests/emulator)). Do not edit by hand.

Frames are `6F cmd action len_lo len_hi payload… 8F` or `6E 01 cmd payload… 8F`. Every 6F set is answered with the generic ack `01 81 [cmd, status]` (status 0 = applied, 1 = rejected or no data, 2 = no handler). The stock firmware ignores 6E frames and drops 6F frames with an empty payload.

## Pairing and identity

### `bind.start`

**Start binding**. Starts pairing. In QR mode the watch shows a QR code for the app to scan.

| | |
|---|---|
| Frame | 6F `0x93` set `71`, written to `8001` |
| Request | `[mode]`: `02` QR code (default), `01` confirm on watch; or `00 uid_le32` to rebind a known user. |
| Response | `01 81 [93, status]` ack, or `93` with a little-endian user ID. |
| Completes on | `0x93`; timeout 30000 ms |
| Evidence | Android 6F stack |
| Stock firmware | handled |
| Example | `6F 93 71 01 00 02 8F` |
| Emulator | `6F 01 81 02 00 93 00 8F`<br>→ `Ack { command: 147, status: 0 }` |

### `bind.end`

**Finish binding**. Completes pairing; the watch leaves the bind screen.

| | |
|---|---|
| Frame | 6F `0x94` set `71`, written to `8001` |
| Request | `[01]` |
| Response | `01 81 [94, status]` ack, or `94 [flag]` where 1 = first bind. |
| Completes on | `0x94`; timeout 5000 ms |
| Evidence | Android 6F stack |
| Stock firmware | handled |
| Example | `6F 94 71 01 00 01 8F` |
| Emulator | `6F 01 81 02 00 94 00 8F`<br>→ `Ack { command: 148, status: 0 }` |

### `identity.watch_id`

**Read watch ID**. Reads the watch's identifier.

| | |
|---|---|
| Frame | 6F `0x02` check `70`, written to `8001` |
| Request | `[00]` |
| Response | ASCII ID, e.g. `FCP03A18050801000000`; non-printable IDs are shown as hex. |
| Completes on | `0x02`; timeout 10000 ms |
| Evidence | official iOS app |
| Stock firmware | handled |
| Example | `6F 02 70 01 00 00 8F` |
| Emulator | `6F 02 80 14 00 46 43 50 30 33 41 31 38 30 35 30 38 30 31 30 30 30 30 30 30 8F`<br>→ `WatchId { id: "FCP03A18050801000000" }` |

The stock firmware drops 6F frames with an empty payload, so the empty request the iOS app sent is never answered; `[00]` (or `[01]`) is.

### `identity.version`

**Read firmware version**. Reads the 20-character version string; the `B` segment identifies patched builds.

| | |
|---|---|
| Frame | 6F `0x03` check `70`, written to `8001` |
| Request | `[01]` |
| Response | `[01] ASCII version`, e.g. `01 'A0.2R0.4T0.0H0.0B0.1'`. A leading byte ≤ 06 is dropped. |
| Completes on | `0x03`; timeout 8000 ms |
| Evidence | official iOS app |
| Stock firmware | handled |
| Example | `6F 03 70 01 00 01 8F` |
| Emulator | `6F 03 80 15 00 01 41 30 2E 32 52 30 2E 34 54 30 2E 30 48 30 2E 30 42 30 2E 31 8F`<br>→ `Version { text: "A0.2R0.4T0.0H0.0B0.1", parsed: Some(FirmwareVersion { raw: "A0.2R0.4T0.0H0.0B0.1", segments: ["A0.2", "R0.4", "T0.0", "H0.0", "B0.1"], apollo_tag: Some("B0.1"), is_patched: false }) }` |

After an OTA the watch can take several seconds to answer.

## Time and profile

### `time.set`

**Set date and time**. Sets the watch clock and time zone. With hand calibration set, the analogue movement restarts from its calibrated position.

| | |
|---|---|
| Frame | 6F `0x04` set `71`, written to `8001` |
| Request | `year_le16 month day hour minute second 00 calib sign tz_hour tz_minute` (sign 1 = east of UTC). |
| Response | `01 81 [code, status]` ack; status 0 = applied. |
| Completes on | `0x04`; timeout 3000 ms |
| Evidence | Android 6F stack |
| Stock firmware | handled |
| Example | `6F 04 71 0C 00 EA 07 0A 0B 0C 1E 00 00 00 01 01 00 8F` |
| Emulator | `6F 01 81 02 00 04 00 8F`<br>→ `Ack { command: 4, status: 0 }` |

Hardware-probed: Norm Two accepts the Android 12-byte payload. A check (`70 [00]`) reads back `year_le16 month day hour minute second`.

### `profile.set`

**Set body profile**. Writes the body profile the watch's calorie model reads (Mifflin-St Jeor resting energy, Harris-Benedict-scaled activity).

| | |
|---|---|
| Frame | 6F `0x30` set `71`, written to `8001` |
| Request | `sex age height_cm weight_0.1kg_le16` (sex 0 = male, 1 = female). The factory record is male, 20, 170 cm, 60.0 kg. |
| Response | `01 81 [code, status]` ack; status 0 = applied. |
| Completes on | `0x30`; timeout 5000 ms |
| Evidence | NormConnect rewrite |
| Stock firmware | handled |
| Example | `6F 30 71 05 00 01 29 B6 2C 03 8F` |
| Emulator | `6F 01 81 02 00 30 00 8F`<br>→ `Ack { command: 48, status: 0 }` |

The firmware copies the five bytes verbatim into its profile record and reconfigures the activity model. A check (`70 [00]`) reads the record back with `strcpy`, so a male profile (leading zero) reads back empty; the SDK has no get for that reason. The `0x05` user-info write the earlier apps sent is acked but leaves the profile unchanged.
